# 🎓 CampusConnect

**CampusConnect** is a college student web application that serves as a centralized hub for campus life — combining social feeds, academics tracking, events, messaging, marketplace, and more into one seamless platform.

---

## 📁 Project Structure

```
campusconnect/
├── index.html          ← Main app (single-page application)
├── css/
│   └── style.css       ← Full design system & component styles
├── js/
│   └── app.js          ← App logic, navigation, interactivity
└── README.md
```

---

## 🚀 Features

| Module | Description |
|---|---|
| 🏠 **Home Feed** | Social feed with posts, likes, comments, trending topics, today's classes & deadlines |
| 📚 **Academics** | Attendance chart, CGPA donut, subject-wise progress bars, assignment tracker |
| 🗓️ **Timetable** | Full weekly class schedule with color-coded subjects |
| 🎉 **Events** | Campus event listings with RSVP functionality, category filters |
| 👥 **Study Groups** | Create/join study groups, see member counts and activity |
| 💬 **Messages** | Chat UI with real-time-like messaging, auto-reply simulation |
| 🛍️ **Marketplace** | Buy/sell items between students with contact integration |
| 🔎 **Lost & Found** | Report lost/found items, contact reporters |
| ⭐ **Clubs** | Campus club listings with join functionality |
| 🔔 **Notifications** | Notification center with read/unread states |
| 👤 **Profile** | Student profile with stats, skills, achievements |

## 🛠️ Tech Stack

- **HTML5** — Semantic, structured markup
- **CSS3** — Custom design system with CSS variables, animations, responsive grid
- **Vanilla JavaScript** — No frameworks, no dependencies
- **Google Fonts** — Syne (headings) + DM Sans (body)
- **Canvas API** — Attendance bar chart, CGPA donut chart

---

## 🎨 Design System

- **Theme:** Dark mode with vibrant accent colors
- **Primary Font:** Syne (headings, stats)
- **Body Font:** DM Sans
- **Accent Colors:** Blue `#63b3ed`, Orange `#f6ad55`, Green `#68d391`, Purple `#9f7aea`, Pink `#f687b3`
- **Components:** Cards, tags, buttons, modals, tabs, progress bars, chat bubbles, avatar stacks

## ▶️ How to Run

Simply open `index.html` in any modern web browser:

```bash
# Option 1: Direct open
double-click index.html

# Option 2: Using VS Code Live Server
code campusconnect/
# Then click "Go Live" in VS Code status bar

# Option 3: Python simple server
cd campusconnect
python -m http.server 8000
# Open http://localhost:8000
```

> No build step, no npm install, no backend required. Pure frontend!

---

## 📱 Responsive

Works on desktop and tablet. Sidebar collapses on narrow screens. Chat panel adapts to single-column layout on mobile.
